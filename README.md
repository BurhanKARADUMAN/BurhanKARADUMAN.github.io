# Burhan Karaduman — Research Portfolio

Static, mobile-friendly GitHub Pages website for **detector physics, nuclear and radiation instrumentation, and medical imaging systems**.

- Live URL (after publishing): https://burhankaraduman.github.io/
- Site entry point: `index.html`
- Print-friendly CV: `cv.html`
- Downloadable public CV: `assets/Burhan_Karaduman_Academic_CV.pdf`
- No external build dependencies; vanilla HTML, CSS and JS
- Project images are bundled locally and labeled by evidence status

## Preview locally
Open `index.html` in a browser or run `python -m http.server 8000` in the repository root.

## Publish
Use GitHub repository **`BurhanKARADUMAN.github.io`** as a public user-site repository, then configure **Settings → Pages → Deploy from a branch → main / (root)**. This is a non-clinical research portfolio. Please review the CV and links before sharing publicly.

## Source integrity
Never interpret an illustrative demo image as an experimental result. The proton benchmark metrics link to their research data; the historical Higgs analysis and MuonScope images are labeled accordingly.
